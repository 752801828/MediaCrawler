# 登录前任务横幅实施计划

## 目标

在创作者运营公开爬虫任务启动浏览器和显示二维码之前，输出无阻塞的中文任务横幅，帮助操作者确认平台、账号目录和当前目标。

## 实施步骤

1. 在 `creator_ops/crawler_bridge.py` 增加纯格式化函数：
   - 转换平台、任务类型、账号角色和开关状态。
   - 输出账号模板、绝对目录、目标数量和完整目标列表。
   - 不读取或输出任何密钥、Cookie 或登录凭据。
2. 增加横幅输出函数：
   - 使用终端即时输出并强制刷新。
   - 在 `run_public_task()` 完成配置作用域设置后、`init_db()` 前调用。
3. 扩展 `tests/creator_ops/test_crawler_bridge.py`：
   - 验证抖音作品评论任务的完整内容。
   - 验证小红书创作者任务的平台、角色和任务名称。
   - 验证横幅早于数据库初始化和浏览器工厂调用。
   - 验证输出不包含敏感配置字段。
4. 运行定向测试、全量测试和 `git diff --check`。
5. 提交实现并推送到 `752801828/MediaCrawler` 的当前功能分支。

## 验收

- 每次公开爬虫任务开始都显示横幅。
- 横幅早于浏览器和二维码。
- 不阻塞任务。
- 不泄露敏感信息。
- 所有测试通过。
