# 抖音创作者后台身份验证等待设计

## 目标

抖音创作者后台任务启动后，浏览器窗口持续保持开启，让操作者完成登录、短信、刷脸等人工步骤。投稿数据表出现后，采集任务自动继续。

## 方案

仅调整 `DouyinCreatorCollector` 的数据表等待流程：

1. 打开抖音创作者后台后，持续尝试进入投稿列表。
2. 从任务启动开始取消投稿数据表的自动等待超时，不依赖任何登录或验证页面文案。
3. 等待期间不自动点击短信、刷脸或发送验证码，由操作者在浏览器内完成。
4. 登录页、短信输入页、二维码页和身份验证页之间的任何跳转都继续等待。
5. 只有投稿数据表真实出现，才结束等待并开始解析。
6. 数据表出现后沿用现有解析、保存和同步流程。
7. 操作者可以在 CMD 中按 `Ctrl+C` 主动停止任务。

## 范围

- 只修改抖音创作者后台采集。
- 不修改小红书、公开作品、评论、Tag、MySQL 或飞书同步逻辑。
- 不增加新的运行参数或配置项。
- 不生成额外的验证报告。
- 无限等待从抖音创作者后台任务启动时启用，并持续到数据表出现。

## 测试

增加任务直接进入登录页后仍持续等待、页面多次跳转后数据表出现并自动继续的测试。运行创作者采集相关测试，确保正常页面解析行为不变。
