# 抖音 Water API 评论间隔调整设计

## 目标

仅将抖音 `water_api` 评论抓取的请求间隔从 2 秒缩短为 1 秒，以减少一级、二级评论翻页等待时间。

## 范围

- `water_api` 的作品并发保持为 1。
- `legacy` 模式继续使用全局 2 秒间隔和并发 1。
- 小红书、快手、微博等其他平台不受影响。
- 不修改评论接口、翻页终止条件、会话刷新、重试、失败回退、数据库及飞书映射。

## 实现

增加抖音 `water_api` 专用间隔配置，默认值为 1 秒。创建 `WaterAccountCommentApiFetcher` 时读取该专用配置，不再使用全平台共用的 `CRAWLER_MAX_SLEEP_SEC`。作品仍按现有顺序逐个执行。

## 错误处理

沿用现有行为：接口请求失败时刷新水号会话并重试；单个作品最终失败时回退到 `legacy`。回退路径继续使用原来的 2 秒间隔。

## 测试

先增加一个失败测试，验证 `water_api` Fetcher 收到 1 秒专用间隔，同时验证 `legacy` 仍读取全局 2 秒配置。完成最小实现后运行抖音评论相关测试及完整测试集。
